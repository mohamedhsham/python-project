# python-project

# Basic Features

* User registration
* User login with limited attempts
* Link Visa card
* Check balance
* Deposit money
* Withdraw money
* Transfer money between users
* Transaction history
* Input validation

# Bonus Features

* Multiple linked cards
* Remove linked cards
* View last 5 transactions
* Transfer fee
* Daily transfer limit

## Project Structure

* `Main.py` — menus and program flow
* `auth.py` — registration and login
* `operations.py` — wallet and card operations
* `validation.py` — input validation
